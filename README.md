# unnamedlang

Currently this is an optimizing pipeline for my own general-purpose programming language. That being said, it does not include runtime at this moment or may be incomplete at places. The pipeline covers these components:
- Lexer
- Parser
- HIR (AST, Typed AST)
- MIR (TAC as SSA)
- SSA Optimizer

For examples of source code for programming language (which has no name yet) refer to **examples/** directory. Some of them will be covered as demonstration. For that refer to [demo](docs/demo.md).
